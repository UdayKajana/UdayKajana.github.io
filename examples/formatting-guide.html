Notes formatting guide

A cheat sheet to keep in Notes. Every line is written in the format it describes: the Heading 1 line is a Heading 1, the sub-heading line ends with a colon, each callout is its own callout, and so on. Paste it once to see every rule and how to type it. Also see the AI agents example.

  1. Click Copy note.
  2. In Notes, add a new page (Space on a laptop, triple-tap on a phone) and click into the editor.
  3. Paste (Ctrl+V / ⌘V), name it, and save. Open it to see the formatted page.
