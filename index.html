Welcome to Code Knowledge Manager

About This Application

Code Knowledge Manager helps you organize and access your programming knowledge in a structured way. Store code snippets, explanations, and documentation in a hierarchical tree structure for easy reference.

Key Features

  • Hierarchical Organization: Store your code knowledge in a tree structure with parent-child relationships
  • Multi-language Support: Add code snippets in Python, Java, SQL, and other languages
  • Search Functionality: Quickly find specific code snippets or concepts
  • Real-time Updates: All changes are saved to Firebase in real-time

Getting Started

  1. Navigation Panel:
    • The left panel shows your knowledge tree
    • Click on any item to view its details
    • Toggle between Tree and Notes views using the button in the top bar
  2. Adding Content:
    • Click the "+" button in the top-right corner to add new elements
    • Select a parent location from the dropdown
    • Enter a name and description
    • Add code snippets in different languages using the tabs
  3. Editing Content:
    • Click the pencil icon on any content to edit it
    • Toggle the "Modify Existing Element" switch to edit instead of create
    • Select the element you want to modify from the dropdown
  4. Searching:
    • Use the search bar at the top to find specific content
    • Results will filter in real-time as you type

Interface Tips

  • Collapse/expand the left panel using the arrow button in the top-left
  • Click on parent nodes to expand/collapse their children
  • Code snippets support syntax highlighting for better readability
  • Switch between different code languages using the tabs in the code viewer
